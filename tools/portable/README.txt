AMULITH: THE ROOTS REMEMBER

Windows: double-click Play-Amulith.bat. Requires Python 3 already installed.
macOS/Linux: run python3 launch.py, or run ./play-amulith.sh.
Keep the launch window open while playing. No internet or other packages needed.

Choose Bloom or Blight with the mouse, 1/2, or a controller.
Move: WASD / arrow keys / left stick
Pulse and hold beside a shard: Space / A
Dash: Shift / B
Talk to a forest spirit: F / X
Ask Amulith for a direction: E / Y
Lantern: Q lowers, R raises / triggers
Pause: Esc / Start

Story mode reduces combat damage. Challenge mode uses the original damage.
Conversations pause the world. Chronicle entries stay in this browser.
No Jetson, webcam, Arduino, model, API key, or account is required.
